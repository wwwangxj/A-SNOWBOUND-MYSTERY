# 暴雪山庄 V4.10 · 真相揭晓与中文旁白版

一款纯前端的互动推理游戏（视觉小说 + 漫画分镜 + 像素拼图）。单文件 HTML 即可运行，无需服务器、无第三方音频素材、无网络依赖。

## 直接试玩

| 版本 | 文件 | 说明 |
| --- | --- | --- |
| 完整试玩 | `暴雪山庄_V4.10_直接试玩.html` | 完整流程，旁附 `交接存档.html` |
| 开发试听 | `暴雪山庄_V4.10_开发试听版.html` | 保留场景速切，便于逐段听旁白与配乐 |
| 推演 / 相册直达 | `终局推演_直接预览.html` | 直达终局推演与相册段落 |
| 源码入口 | `package/my-world/index.html` | 未打包的开发目录版本 |

用浏览器（Chrome / Edge 最新版）直接打开任意 HTML 即可游玩。首次交互后启用三层声音。

## 版本要点（V4.10）

- **真相揭晓**：新增揭晓阶段，含独立配乐与 11 段中文旁白
- **三层声音系统**：右下角「♫ 音景」可分别调节 BGM、环境音、交互音效、旁白音量，支持总静音；仅记住音乐偏好，不写关卡存档
- **本地合成音频**：新阶段原创 BGM、独立风雪环境声、原交互音效、本地合成旁白，无第三方歌曲 / 录音 / 采样
- **界面氛围**：冷暖色调跟随剧情阶段变化，完整漫画保留原色
- **相册**：像素拼图与整张相册保留，停留时长按实际朗读长度调整，支持重听与暂停续播
